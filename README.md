# ✅ Python To-Do List

A command-line task management app built with **Python**. Each task holds structured attributes and the app supports full CRUD operations with sorting and error handling.

---

## 📋 Features

- Add a task with full details: name, description, category, priority, and status
- View the full task list
- Edit any task's details or status
- Delete tasks
- Sort tasks in ascending or descending order
- Error handling for invalid inputs

---

## 🗂️ Task Attributes

| Attribute | Description |
|---|---|
| Name | Task title |
| Description | Brief details about the task |
| Category | Type/group of the task |
| Priority | Importance level |
| Status | Current state (e.g. pending, done) |

---

## ▶️ How to Run

```bash
python ToDo.py
```

No external dependencies — pure Python.
